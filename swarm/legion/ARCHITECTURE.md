## 文本架构树

```
军团统帅（+1）
├── 战略与治理部
│   ├── 总架构师（EX）— 系统边界、非功能顶格、风险纲要 → 末端：蜂群
│   └── 合规与采购参谋（EX）— 条款↔控制映射、约束包 → 中间：为 MG 提供 PENETRATING 约束包（可与统帅并联路由）
├── 产品与作战部
│   ├── 产品总监（MG）— Backlog、里程碑、验收口径 → 末端：蜂群
│   └── 技术项目经理（MG）— 依赖、联调、环境节奏 → 末端：蜂群
├── 平台与数据部
│   ├── 数据平台负责人（MG/OP）— 主数据、时空模型、API → 末端：蜂群
│   └── 集成工程师（OP）— 外部系统、仿真桩、回归环境 → 末端：蜂群
├── 安全与可信部
│   └── 安全架构师（EX）— 威胁建模、加密与密钥、审计 → 末端：蜂群
├── 体验与一线部
│   └── 指挥席 UX 负责人（OP）— 流程、信息密度、误操作防护 → 末端：蜂群
└── 质保与演练部
    └── SRE / 演练官（MG）— 灰度、压测、灾难演练、运行手册 → 末端：蜂群
```

| 部门       | 性质   | 说明 |
|------------|--------|------|
| 战略与治理 | 核心   | 目标、合规、架构顶层 |
| 产品与作战 | 核心   | 范围与波次 |
| 平台与数据 | 核心   | 数据事实源与集成 |

**渐进展开建议（控 Task 预算）**：第一波仅启用 **总架构师、产品总监、安全架构师** 三条末端蜂群；回声与 Gate 通过后扩展 **数据平台 / 集成 / SRE / UX**。

## 信息流向（跨部门）

1. **军令状**（`MISSION-BRIEF.md`）→ 全员穿透；②③⑤ 至少下至蜂群 R1–R4（按蜂群 `.mdc`）。
2. **总架构师** → 为 **产品总监、数据平台负责人、SRE** 提供架构与 NFR 摘要。
3. **合规参谋** → 为 **产品总监、安全架构师** 提供 **PENETRATING** 约束包（原文复制条目标签项）。
4. **安全架构师** → 为 **SRE、集成工程师** 提供安全基线与审计要求。
5. **产品总监** → **技项经理、UX** 的范围与验收口径。
6. **技项经理** → **集成工程师、SRE** 的时序与环境门闩。
7. **数据平台负责人** → **集成工程师** 的 API/数据契约。
8. **集成工程师** → **SRE** 的部署拓扑与回归入口。
9. 全部末端产出 → **军团统帅** 汇流 → **回声校验**（`ECHO-CHECK.md`）。
