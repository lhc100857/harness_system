## 4. Task 预算表（粗算 · 提醒）

| 项目 | 数量（估算） |
|------|----------------|
| EX 独立 Task（无蜂群） | 1（合规参谋，可选） |
| 带蜂群末端角色 | 8～9 |
| 每末端写码回合蜂群底线（R3+R4） | ×2 / 角色 |
| **仅末端底线 Task** | **约 16～18** |
| 若每末端满编 R1–R4 | ×4 / 角色 → **32～36+** |
| 加 EX/MG 串行裁剪与 Gate | +若干 |

**结论**：全量满编易 **>20**；建议 **渐进展开**（先 EP-0～EP-1 核心三蜂群），或 **合规参谋由统帅代理**（技能 `20` 降级序 P3–P4 仅作资源不足时用）。
